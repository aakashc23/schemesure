# Refusal-threshold analysis

The retriever refuses a question outright when the **best chunk similarity is below a threshold** (currently **0.45**). This page looks at the best-score distributions and sweeps the threshold. It uses saved retrieval results only: 0 LLM calls.

> **Read this as a consistency check, not a validation.** The value 0.45 was originally chosen (docs/DECISIONS.md) from about 22 queries that overlap this golden set, so it was not tuned on held-out data. Showing that it behaves sensibly here does not show it will generalise.

## Variant `raw`

*Production refuses on the **normalized** query's score. The raw variant shows what would happen without the LLM normalizer; Hindi/Hinglish scores are expected to be lower here.*

### AUROC of best score (1.0 = perfectly separable, 0.5 = no signal)

- answerable vs **all** unanswerable: **0.750**
- answerable vs **off_topic** only: **0.989**

The threshold is only expected to catch `off_topic`. `fake_scheme` and `not_indexed` questions look like real scheme questions and score high, so they are left to the claim-level guardrail.
